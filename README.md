# LEGO MOD Firmware

Firmware ESP32 para el sistema IoT modular LEGO.

## Características

- Actualización OTA desde GitHub Releases
- Gestión WiFi con portal AP
- Control por botón (triple click para OTA)
- Rollback automático si falla

## Compilar

```bash
pio run
```

## Release

```bash
./release.sh
```
